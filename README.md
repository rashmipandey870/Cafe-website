# Mellow & Meadow Café — Full-Stack Management & Ordering Website Handover Documentation

Welcome to the production-ready source code repository for **Mellow & Meadow Specialty Café & Brunch**. This website is built using **vanilla PHP 8+**, **MySQL**, **Bootstrap 5**, and **Vanilla JavaScript**. It is fully self-contained, database-portable, secure, responsive, and optimized for shared hosting environments running cPanel and Apache.

## 2. Security Highlights

To deliver a **client-ready, commercial-grade product**, the following security measures are implemented directly into the codebase:

1. **SQL Injection Protection**: Every database interaction uses **PDO Prepared Statements** with parameter binding. Raw, concatenated input variables are never executed.
2. **Cross-Site Scripting (XSS) Prevention**: All dynamic values output into public HTML pages are escaped using the custom `escape()` wrapper (which maps to `htmlspecialchars` with `ENT_QUOTES` and `UTF-8`).
3. **Cross-Site Request Forgery (CSRF) Guard**: Every state-changing form (in both frontend checkout/reservations and all admin CRUD features) includes a hidden token input generated via `csrf_field()` which is verified server-side on POST submissions.
4. **GET CSRF Hardening**: Deactivations, visibility toggles, and deletions triggered via URL clicks are verified against session variables using `verify_csrf_get($_GET['token'])` to prevent unauthorized cross-site scripts execution.
5. **Database Configuration Safety**: Connection details are isolated inside `config/db_config.php`. The root `.htaccess` file blocks direct access to this directory, returning a `403 Forbidden` response to any direct browser downloads.
6. **Price Integrity**: Cart item prices in the browser's local storage are ignored during checkout. The server decodes only the `item_id` and `quantity`, fetches actual prices directly from the database, and recalculates the grand total server-side before registering the order.
7. **Secure Image Upload Filter**: The `upload_image()` function enforces a maximum file size (2MB), restricts extensions (`.jpg`, `.jpeg`, `.png`, `.webp`), and runs `getimagesize()` to confirm the uploaded file's MIME type matches the declared extension.
8. **Upload Script Block**: The `uploads/.htaccess` file strips handlers and types for scripting languages, preventing attackers from executing uploaded `.php` backdoors.
9. **Production Error Silencing**: Database connection exceptions in `config/database.php` write detailed technical logs to the server error log but output a friendly, non-revealing "Under Maintenance" screen to customers to prevent leaking file directories or credentials.
10. **Installer Lockout**: Once `config/install.lock` is created on setup completion, both `install.php` and `tools/database-check.php` immediately lock down and return a `403 Forbidden` error page.

## 3. Local Development Setup (Two Support Pathways)

Because local environments vary, the Mellow & Meadow application supports two development setups:

### Approach A: Standalone MySQL Service (e.g. MySQL80 on Port 3306)
If your computer already runs MySQL as a standalone Windows service:
1. Open PowerShell or Command Prompt, navigate to the project directory, and start PHP's built-in server:
   ```bash
   php -S localhost:8000
   ```
2. Open your browser and navigate to: **[http://localhost:8000/install.php](http://localhost:8000/install.php)**.
3. In the installer form, set **Database Host** to `127.0.0.1`, **Port** to `3306` (or `3307`), enter your custom MySQL `root` password, and click **Test & Install**.
4. The database is created (if credentials allow), seeded, and connected immediately!

### Approach B: XAMPP / WAMP Integrated Server
If you want to use the integrated MySQL server provided by XAMPP or WAMP:
1. Stop the standalone Windows MySQL service to free up port 3306. Run PowerShell as **Administrator** and run:
   ```cmd
   net stop MySQL80
   ```
2. Open the **XAMPP Control Panel** and click **Start** next to **Apache** and **MySQL**.
3. Move the `cafe-website` directory into the XAMPP public directory (`C:\xampp\htdocs\`).
4. Navigate to **[http://localhost/cafe-website/install.php](http://localhost/cafe-website/install.php)**.
5. In the installer, set **Database Host** to `127.0.0.1`, **Port** to `3306`, keep the password **empty**, and click **Test & Install**.

## 4. Production Deployment & Client Handover Workflow

To deliver this application to a café owner client:

### Step 1: Upload Files
Upload the project files to the client's cPanel file directory (e.g., `public_html/`) using the cPanel File Manager or FTP.

### Step 2: Set Up Dedicated MySQL User (Do NOT use root in production)
1. Go to cPanel **MySQL Databases**.
2. Create a database for the café (e.g., `mellow_meadow_cafe`).
3. Scroll down to **MySQL Users** and create a new dedicated application user (e.g., `mellow_meadow_app`) with a strong, secure password.
4. Add the user to the database and assign only the privileges required by the application:
   * `SELECT`, `INSERT`, `UPDATE`, `DELETE`, `CREATE`, `DROP`, `INDEX`, `ALTER`
   * Avoid assigning `SUPER`, `GRANT OPTION`, or administrative privileges.

### Step 3: Run the Web Installer
1. Navigate to **`https://yourdomain.com/install.php`**.
2. Enter the dedicated database name, username, and password created in Step 2.
3. The installer connects, imports `database/cafe_database.sql`, writes `config/db_config.php`, and locks the setup wizard by creating `config/install.lock`.

### Step 4: Final Lockdown
Verify that visiting `https://yourdomain.com/install.php` and `https://yourdomain.com/tools/database-check.php` returns a `403 Forbidden` page. 
* *Best Practice*: Delete the `tools/` directory entirely from the server before final handover.

## 5. Backups and Database Recovery

### 1. Exporting the Database (Backup)
To back up the café's database from cPanel:
1. Open **phpMyAdmin** in cPanel.
2. Select your café database (e.g., `mellow_meadow_cafe`).
3. Click the **Export** tab, choose the **Quick** export method, and click **Go** / **Export** to download the SQL dump file.
4. Store the SQL file securely.

### 2. Importing the Database (Restore / Migration)
To restore a backup or migrate local data to the production database:
1. Open **phpMyAdmin** and select the destination database.
2. If restoring over an existing setup, drop all tables first to avoid naming collisions.
3. Click the **Import** tab, click **Browse**, select your SQL file, and click **Import**.
4. If database credentials changed, delete `config/install.lock` and run the installer again, or modify credentials directly in `config/db_config.php`.

### 3. Media Assets Backup
To backup menu photographs, promotion banners, and gallery photos:
1. Log in to cPanel File Manager.
2. Locate and select the `uploads/` directory.
3. Click **Compress**, select **Zip Archive**, and download the generated zip file.
